# 使用指南

## 第一次打开

鼠标靠近屏幕顶部的小岛会展开功能面板。左右箭头和底部圆点切换页面；在列表内部滚轮查看更多内容。托盘菜单可打开设置、控制开机启动或退出程序。

设置里的功能显示开关可以隐藏不常用的页面；隐藏页面不等于删除它的数据。

## 界面语言

在「设置 → 常规 → 语言」选择「跟随系统」「简体中文」或「English」，立即切换并自动保存，重启后保留选择。升级旧版时默认继续使用简体中文；跟随系统按 Windows 显示语言选择中文或英文，其他系统语言回退到英文。

当前覆盖世界时钟、页面导航、常规设置和顶部日期／时段文字；其他功能页仍保留原有中文文案。邮件、待办、文件名等用户内容不会被翻译。世界时钟支持在任一界面语言下搜索中文城市名、英文名或 IANA 时区。

## 吉祥物表情

在「设置 → 常规 → 岛体显示」开启 FloatIsle 吉祥物，通过「表情预览」选择 20 种状态并点击「预览」。表情会在小岛收起后播放，完成后恢复自动状态；顶部停靠且未进入极简或自动避让状态时可用。播放音乐、专注、低电量、休眠与额度刷新时仍会自动显示相应表情。

表情的嘴型词汇与状态映射适配自 Aora Bot，许可与来源见 LICENSES.md 和 THIRD_PARTY_NOTICES.txt。

## 世界时钟

切换到「世界时钟」页，可查看默认的北京、伦敦和纽约时间。每行显示当地时间、日期、相对本地的时差，以及今天／昨天／明天标记。

- 在「设置 → 世界时钟」搜索中文城市名、英文名称或 IANA 时区，添加、移除和上下调整城市；最多 6 个，岛内每屏 3 个，用右下角箭头切换。
- 点击 `−1h` / `+1h` 同时查看各地前后时刻，最多前后 24 小时；点击「回到此刻」恢复实时显示。对照不会修改系统时间。
- 12／24 小时制跟随「设置 → 常规」的时钟设置。城市列表自动保存，换算完全离线，并按时区数据库处理夏令时。
- 每行底部标出当地一天中的位置；日间参考范围固定为 06:00–18:00，不表示真实日出日落。
- 岛内点击「地球」切换到离线地球视图，点击「展开」打开更大的世界时钟窗口。展开窗口也可切换城市列表和地球；点击城市卡片会在地球上定位，拖动地球可旋转，底部菜单可跳转到已添加城市。
- 地球按当前时刻绘制昼夜示意；城市位置采用所选时区的代表城市坐标。世界时钟不提供天气数据。

## 邮箱

在「设置 → 邮件」添加完整邮箱地址，选择服务商并填写授权码或 App 专用密码。不要把密码发送到聊天、Issue 或截图里。

| 邮箱 | 获取连接凭据 |
| --- | --- |
| QQ | QQ 邮箱网页版右上角「设置」→「账号与安全」→「安全设置」→「POP3/IMAP/SMTP/Exchange/CardDAV 服务」→开启服务并生成授权码 |
| 163／126 | 邮箱网页版「设置」→「POP3/SMTP/IMAP」→开启 IMAP，并按页面验证生成客户端授权密码 |
| 腾讯企业邮 | 网页版设置中的客户端收发设置；企业管理员可能限制 IMAP 或第三方客户端 |
| iCloud | Apple 账号开启双重认证后，在账号安全页面生成 App 专用密码 |
| Gmail | Google 账号开启两步验证后生成应用专用密码；单位账号可能由管理员禁用此入口 |

以服务商当前页面为准，FloatIsle设置页也提供对应说明和网页入口。Gmail 在部分网络环境下需要能够访问 Google；FloatIsle不会替你改变系统网络设置。

连接后读取最近 20 封邮件；运行期间列表最多保留 60 封。新邮件优先通过 IMAP IDLE 接收，并有定期防漏检查；服务器、网络及服务商投递耗时仍会影响实际到达时间。

验证码卡片显示来源与主题，点击即可复制。点邮件列表进入详情，滚轮查看正文；「阅读全文」打开独立阅读窗口。正文内的网页链接交给默认浏览器打开。

## 日程

在「设置 → 日程」选择平台，填写平台提供的 CalDAV 连接信息。只登录或安装飞书、钉钉、企业微信桌面客户端，不会自动授予FloatIsle日历读取权限。

- 左侧月历选择日期；右侧按时间显示日程，全天安排在前。
- 大卡片显示选中的日程；滚轮只滚动下方列表，点击其他条目切换大卡片。
- 跨天日程会出现在覆盖的日期中。结束时刻按日历提供的数据展示。
- 自动同步默认每 5 分钟进行；点击右上角更新时间可手动刷新月份。
- 提前提醒时间可在设置中选择 5／15／30 分钟；全天安排展示在日历中，不在午夜弹出会议提醒。
- 普通邮件正文中的日期不会加入日程；带日历附件的正式邀请会自动显示。
- 邮件日程右侧的 × 可忽略该日程，停止显示与提醒；在邮件详情或全文窗口选择「恢复日程」可恢复。忽略邮件来源不会删除工作日历中的对应安排。

**当前边界：** 邮件日程依赖当前加载的邮件记录，不是完整邮箱归档；复杂的批量重复规则修改可能提示不支持。日历同步失败会显示错误，不能把“已连接”当成所有日程都已成功同步。程序退出、电脑关机或睡眠期间无法持续接收提醒。

## 音乐、专注、饮水与待办

音乐来自 Windows 媒体会话，播放器需要提供系统媒体信息。歌词匹配依赖歌曲元数据和外部服务，个别版本、纯音乐或未找到歌词的歌曲可能无法显示同步歌词。

专注与休息需点击开始，结束后可进入下一阶段。饮水可设置目标、单次量、提醒间隔和时段；记录错误可以撤销。待办提醒是可选项，填写任务后通过日期／时间选择器设置，不需要手写时间格式。

## AI 额度

先登录相应工具，再在FloatIsle AI 额度设置中识别本机账号。多个账号可分别命名、选择配色并决定是否常驻。Codex、Claude、Kimi 的本机登录由原工具管理，FloatIsle不会修改它们的配置。

Grok Bot、Gemini 提供各自的连接入口；会话过期时重新连接。额度接口、订阅类型和服务商策略可能变化，未识别或请求失败时应以对应服务的官方页面为准。

## 更新、卸载与数据目录

双击新版 `FloatIsle-Setup-v版本号-x64.exe`，可通过路径输入框或「浏览…」选择安装文件夹，勾选「创建桌面快捷方式」和「开机自启」，再点击「一键安装」。首次安装默认创建桌面快捷方式、不开机自启；升级默认保留现有选择。安装位置默认为 `%LOCALAPPDATA%\Programs\FloatIsle`，可改为其他有写入权限的文件夹，用户数据仍保存在 `%APPDATA%\FloatIsle`。

升级安装保留数据。若提示FloatIsle正在运行，先从托盘退出，再点击重试。

在 Windows 已安装应用中卸载会移除程序和快捷方式，但保留数据。若要清除账号，先在FloatIsle设置中移除对应连接，避免只删配置文件而留下系统凭据。

## 常见问题

**窗口没有出现：** 检查托盘是否已有实例、是否在全屏应用中、设置是否启用了全屏隐藏。

**邮箱登录失败：** 确认填的是授权码／App 专用密码、IMAP 已启用、账号没有被管理员限制。

**日程连接成功但没有安排：** 手动同步所选月份，确认平台授权的日历包含该日程；出现错误时保留错误文字即可，不要提供密码。

**验证码没有马上出现：** 确认邮件是否已到达收件箱，而非垃圾箱；检查FloatIsle是否运行、连接是否正常。

**图标或布局异常：** 反馈 Windows 版本、屏幕缩放比例、显示器数量和截图。截图先遮挡账号、验证码及私人日程。
